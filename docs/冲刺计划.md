1. **讲"用 RefCov 管着 Kiro 开发 RefCov"。** 仓库里的 `refcov.toml` 一直在管 Kiro 写代码，`.refcov/log.jsonl` 有两百多条带哈希链的真实记录（拦截、读取、保护检查）。从里面整理几个关键时刻，用英文写进 README 和 Kiro 使用说明，演示页回放其中一段。不依赖校准结果，哪条主线都用得上。
2. **一键安装。** 现在要五步（可编辑安装、复制配置、手写带绝对路径的 MCP 配置、复制钩子、登记材料）。`product.md` 里"应该有"的 power 打包就是解决这个的，规则的 Kiro 使用说明也点名问了 powers。打包格式还没查。
