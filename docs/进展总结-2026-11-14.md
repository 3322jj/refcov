# 进展总结（2026-11-14 夜）

EN summary: Status after the 11-14 trials. After more than fifteen diligent runs, skipped reference material was reproduced on a front-end task: with 210 Chrome front-end guides in the workspace, Kiro's default model selection and claude-haiku-5.5 opened no guide in every run and used none of the four guide practices, while claude-sonnet-5.5 read the relevant guides. With RefCov installed, the default setting and Haiku read all 82 required units every time and used the guide practices; Haiku with RefCov matched Sonnet's adoption rate at about a tenth of the credits. Skipping appears when three conditions hold together: a domain the model thinks it knows, a task that can be finished without checking, and a default or cheap model. This file lists the evidence, the pitch, what each earlier trial is still good for, what is committed, what is still open, and what Kiro needs to sync.

Claude 写。每次接上工作时和 `docs/冲刺计划.md` 一起看。

## 1. 最重要的发现

偷懒能稳定复现了，而且知道它在什么条件下出现。三个条件同时满足才会出现：

1. **AI 自以为熟悉的领域**（例如前端）；
2. **不查也能交差**（老写法照样能跑，不会算错、不会报错）；
3. **默认或便宜的模型**（Kiro 默认的自动选模型、claude-haiku-5.5）。

前面十几次（GIS 陷阱、视频、网店约定、随口提问、120 份工单）测不出来，是因为题都能靠搜索直接找到答案、或者不查就做不对，而且大多用的是固定的 claude-sonnet-5.5。用户判断"方向没错，是方法问题"，是对的；前端指南这个材料也是用户提出的。

## 2. 主要证据：前端指南试验

详见 `docs/前端指南试验结果.md`。

- 材料：Chrome 官方现代前端指南（`modern-web-guidance` 包的 `guides/`，210 份，约 2 MB，Apache-2.0），README 一句"前端代码遵循 guides/ 里的指南"。
- 任务（各组提示词完全相同，不提 RefCov、不提读指南）：写一个账户设置页，带确认对话框和表单校验。
- 四根针：任务里四个要求各对应一份指南推荐的新写法（`closedby="any"`、`:user-invalid`、`command`/`commandfor`、`overscroll-behavior` 等）。

| 组 | 次数 | 打开指南 | 推荐写法用上 | 额度 |
|---|---|---|---|---|
| 默认自动选模型，不装 | 4 | 每次 0 份 | 0 / 16 | 0.32–0.46 |
| claude-haiku-5.5，不装 | 2 | 每次 0 份 | 0 / 8 | 0.04–0.05 |
| claude-sonnet-5.5，不装 | 4 | 每次 6–7 份 | 14 / 16 | 1.99–3.79 |
| 默认自动选模型，装 RefCov | 4 | 每次读完 82 个单元 | 16 / 16 | 2.36–3.52 |
| claude-haiku-5.5，装 RefCov | 2 | 每次读完 82 个单元 | 7 / 8 | 0.25–0.26 |

三个结论（只说在这一个任务、kiro-cli 3.3.0、各 2–4 次上测得）：

1. 不装 RefCov 时，默认和便宜的模型每一次都不看规范，凭记忆写完，汇报里对规范只字不提。
2. 装上 RefCov 后，每一次都先读完必看的规范，推荐写法基本全部用上。
3. 最便宜的 Haiku 装上 RefCov，推荐写法的采用率和 Sonnet 不装时相同，额度约为 Sonnet 的十分之一。

## 3. 对外讲法（草稿，定稿前过冲刺计划检查点 4）

> 项目里放着规范，AI 却凭记忆写代码，汇报里还对规范只字不提。装上 RefCov，同样的模型先读完必看的规范再动手，推荐写法基本全用上。最便宜的模型（Haiku 5.5）装上它，推荐写法的采用率和不装的 Sonnet 5.5 相当，额度约为十分之一。AI 读了多少，应该是一个数字，而不是一句"我看过了"。

必须同时交代：每组只有 2–4 次、一个任务；"效果相当"只指四种指南写法，页面在浏览器里好不好用还没测；登记哪 8 份指南是 Claude 按任务挑的，四根针所在的指南都在里面；起作用的是状态行提示和 MCP 读取，关卡一次都没拦。
